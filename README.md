### Telegram бот записи к стоматологу (монолит)

#### Функции
- **/book**: запись на приём (дата → время → ФИО → телефон → подтверждение).
- **/mybookings**: показать будущие записи пользователя.
- **/cancel**: отменить текущий диалог.

#### Хранение данных
- Бронирования сохраняются локально в `bookings.json` рядом с `bot.py`.
- Формат: словарь по датам и времени. Легко мигрировать на БД.

#### Рабочие часы и слоты
- Слоты каждые 30 минут с 10:00 до 18:00 (без воскресений).
- В текущий день скрываются прошедшие слоты.

#### Примечания
- Архитектура: монолит, один исполняемый файл `bot.py`.
- Для продакшена: логи, админ-команды, бэкапы `bookings.json`.
